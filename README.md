# ChatGPT Pet Workshop 🐉

**從零開始，用 GPT 製作、驗收並發布 ChatGPT 虛擬寵物的繁體中文開源教學。**

這裡不只教你「生出一張好看的圖」，更教你區分：**角色圖 → 動作影格 → 16 方向視線 → 圖集 → 品質驗收 → 最後才建立 Pets**。適合第一次製作寵物、不熟悉 Python 與動畫圖集的使用者。

> 非 OpenAI 官方專案。Pets 功能、工具和技術規格會變動；實際操作時以已安裝的 `create-pet` 技能及共享規格為準。這裡不提供官方腳本的複製品，也不保證所有帳號都有相同功能。

## 從哪裡開始？

| 階段 | 你要得到什麼 | 教學 |
| --- | --- | --- |
| ① 準備角色 | 名稱、外觀、原始參考、來源權利 | [製作流程](docs/01-workflow.md) |
| ② 確定主造型 | 能保持一致的 canonical base | [正式工作任務](docs/01-workflow.md) |
| ③ 製作動畫 | 九組動作＋四基準與 16 視線方向 | [動作與方向](docs/01-workflow.md) |
| ④ 驗收再建立 | 正式圖集、逐格證據、動態預覽、Pets 建立 ID | [驗收清單](docs/02-qa-checklist.md) |

### 核心觀念

- **v2 圖集共 11 列：** 前 9 列動作、後 2 列視線方向（各 8 格、總共 16 方向）。
- **方向的定義不能猜：** 0° 向上、90° 向右、180° 向下、270° 向左，不是全身旋轉四個面。
- **不要把圖檔格式預檢當作最後驗收：** `valid: true` 不等於動畫自然，更不等於 Pets 建立成功。
- **先生成、再檢查、最後才上傳：** 保留原始檔與失敗紀錄，沒有通過必要門檻就不要宣稱正式完成。

## 最小開工檢查

- [ ] 能讀取目前版本的 `create-pet/SKILL.md` 與隨附驗收腳本。
- [ ] 已備妥合法使用的角色參考圖、Python 與 Pillow。
- [ ] 已用官方 `prepare_pet_run.py` 建立工作目錄。
- [ ] 已查 `imagegen-jobs.json`，確認 `ready_jobs` 與輸入圖片。
- [ ] 在真正完成**官方驗收與播放檢查**以前，資料保留於私有工作區。

## 專案現況

這是持續整理中的**教學與驗收工作流**，不是可一鍵安裝的寵物產品。玄龍 ZERO 案例仍在素材製作階段；repo **沒有**把未通過審查的候選 PNG／ZIP 當成正式作品發布。
