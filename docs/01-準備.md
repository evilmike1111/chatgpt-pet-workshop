# 01｜準備

## 你需要的東西

1. 一個能使用 Codex 的 ChatGPT 帳號。各方案的額度與可用功能以 OpenAI 官方說明為準；本教學**沒有驗證免費方案能否走完全程**。
2. Codex（桌面版或 CLI 皆可）。
3. 在 Codex 裝好 **Pets** 外掛（work-pets）。它提供：
   - `create-pet` 技能與官方確定性腳本（切圖、組圖集、驗證、方向檢查）
   - 上架工具：`validate_pet_spritesheet`、`prepare_pet_upload`、`create_pet`、`update_pet`、`select_pet`
4. 你的角色構想或參考圖（自己畫的、自己有權使用的圖）。

不需要：本機 GPU、ComfyUI、Photoshop、任何自寫腳本。

## 一分鐘檢查：這個工具真的能用嗎？

在 Codex 輸入：

```text
這是通道測試。1) 用內建圖片生成工具畫一個洋紅色 #FF00FF 背景上的金色圓形，存成 probe.png。
2) 列出你現在能不能使用：image generation、validate_pet_spritesheet、prepare_pet_upload、create_pet、pets_list_pets。
```

判讀：

- 有產出 `probe.png` → 生圖可用。
- 工具清單全部可用 → 可以往下做。
- 任何一項不可用 → 先停，不要改用其他生圖工具硬做（見 [04-常見失敗](04-常見失敗.md)）。

CLI 使用者可以先執行 `codex features list`，確認 `image_generation` 為 `true`。
