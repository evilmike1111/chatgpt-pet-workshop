# 01｜準備

## 硬體與軟體（玄龍實測環境）

| 項目 | 實測 |
|---|---|
| 作業系統 | Windows 11 |
| 顯卡 | NVIDIA RTX 4060 Ti，16 GB VRAM（Qwen-Image-2.1 INT8 單張約 30–40 秒） |
| Python | 3.12，需要 `pillow`、`numpy`（ComfyUI 的環境已有） |
| ComfyUI | 0.43.0，PyTorch 2.14.1 + CUDA 13 |
| 模型 | Qwen-Image-2.1 INT8：`qwen_image_2.1_int8_convrot.safetensors`（UNET）、`qwen3vl_8b_int8_convrot.safetensors`（文字編碼器）、`qwen_image_2.1_vae_bf16.safetensors`（VAE） |
| Codex | 只用來「載入寵物」。需要安裝 Pets 外掛才有驗證腳本；**不需要付費額度** |

模型檔放到 ComfyUI 的 `models\diffusion_models`、`models\text_encoders`、`models\vae`。模型下載與授權請看 ComfyUI 與模型作者的說明，本 repo 不提供。

## 先檢查 ComfyUI 活著

啟動 ComfyUI 後（`python main.py --listen 127.0.0.1 --port 8188`），開瀏覽器看 `http://127.0.0.1:8188/system_stats`，要看到 GPU 名稱與 VRAM。
再看 `http://127.0.0.1:8188/object_info/TextEncodeQwenImage21` 有回應，代表 Qwen-Image-2.1 的節點存在。沒有的話先更新 ComfyUI。
