# 03｜驗收清單

全部打勾才可以上架。每一項都要有**實際的腳本輸出或檔案**，口頭說「通過了」不算。

## 結構

- [ ] 最終圖集剛好 1536 × 2288，8 × 11 格，每格 192 × 208
- [ ] 檔案為 PNG 或 WebP，不超過 20 MiB
- [ ] 必要格子都有內容，未使用格完全透明
- [ ] 沒有殘留的色鍵背景、裁切、溢出到隔壁格、碎片、接縫或意外透明破洞
- [ ] 官方 `validate_atlas`、`validate_pet_quality` 報告皆為 PASS

## 動作（第 0–8 列）

- [ ] 每列格數正確，動作語意正確（例如 running-left 真的往左）
- [ ] 角色、配色、比例前後一致，沒有忽大忽小或基準線跳動
- [ ] jumping 有明顯離地再回到地面
- [ ] idle 不是靜止畫面

## 方向（第 9–10 列）

- [ ] 四方位錨點正確：000 上、090 畫面右、180 下、270 畫面左
- [ ] 16 方向依順時針排列，沒有方向錯、象限錯或反轉
- [ ] 相鄰兩格都能自然銜接，特別檢查 157.5→180 與 337.5→000
- [ ] 沒有鏡像、拼接或單格補做的格子
- [ ] 如果可以，請三位沒看過標籤的人做盲測判斷方向，採多數決

## 預覽與確認

- [ ] 已產出接觸表、方向檢查表、各狀態 GIF、全狀態預覽、MP4、idle→jump→idle 預覽
- [ ] 這些預覽是從**最終圖集**產生的，不是從中間檔案
- [ ] 你已經看過動作並同意
- [ ] `validate_pet_spritesheet` 對最終檔回傳 `valid: true`
