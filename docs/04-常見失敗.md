# 04｜常見失敗

以下都是實際製作時遇到的狀況。

## 本機模型（例如 ComfyUI＋FLUX）生的圖拿來用

本機推論可以成功，但角色會被「重新設計」：角變大、頭身比例改變、裝甲與翅膀細節不同，背景也不是透明的。即使給多張參考圖也鎖不住身份。官方合約要求寵物影像由 `$imagegen` 生成，所以本機生圖只適合用來發想，不要放進正式圖集。

## 用鏡像或拼接補方向格

把頭部拼到身體上，或把左半邊鏡像成右半邊，結構驗證可能會過，但轉頭時輪廓會跳、翅膀左右不一致，而且違反合約。正確做法是整列重生。

## 結構檢查 PASS 就以為完成

格數、尺寸、透明度都對，不代表動作是對的。jumping 變成角色縮放、方向轉反，都只能靠看預覽發現。

## 任務單把生圖輸出位置也禁止了

`$imagegen` 內建工具會先把圖存在 Codex 自己的資料夾（`$CODEX_HOME/generated_images`），再由 Codex 複製到你的專案。如果任務單寫「不准改動 Codex 所在磁碟的任何檔案」，Codex 會因為不能存圖而停下，一張都不生。限制應該寫成「不准改動原始素材」，不要整個磁碟一起禁止。

## 生圖工具不可用時改用其他方式硬做

合約規定生圖不可用時要停在上傳前，不能用程式畫、SVG 或其他工具補一張假圖。
