# 02｜本機免費流程：從舊圖集到桌面上的寵物

這是玄龍 ZERO 實際走過的流程。每一步都有腳本，每一步都有檢查。全程在自己的電腦上做，不呼叫付費服務。

```text
(舊圖集第 0–8 列) ─▶ 01 修復 ─▶ rows09.png ─┐
                                              ├─▶ 03 組圖集 ─▶ 驗證 ─▶ 04 打包 ─▶ 放進 Codex 寵物資料夾
(單格 idle) ─▶ 02 本機生成 16 方向 ───────────┘
```

先設定工作資料夾，之後所有腳本都用它：

```powershell
$env:PET_WORK = "D:\pets\my-dragon"        # 換成你自己的
$env:COMFYUI_DIR = "D:\ComfyUI"            # 你的 ComfyUI 安裝位置
```

## 步驟 0：準備來源

把你已有的、前 9 列可用的圖集放到 `$PET_WORK\inputs\source_atlas.png`（每格 192×208，每列格數：idle 6、running-right 8、running-left 8、waving 4、jumping 5、failed 8、waiting 6、running 6、review 6）。
沒有現成圖集的人，要先用 [05 的付費路線](05-付費替代路線-Codex.md) 或自己的方式做出前 9 列；本教學從「已有前 9 列」開始。

## 步驟 1：確定性修復（不畫新圖）

```powershell
python scripts\01_repair_standard_rows.py
```

做兩件事：移除粉紅／洋紅殘影（色鍵沒去乾淨的像素），以及把 jumping 列整體放大到跟 idle 同樣大小並對齊基準線，同時保留離地。輸出 `repair\rows09.png`、`repair\report.json` 和前後對照 `repair\compare.png`。
**先看 `compare.png`。** 玄龍的 jumping 縮小、review 有殘影，這兩個問題腳本都能處理；如果你的問題不同，要改腳本。

玄龍實測：jumping 的外框從約 155 寬放大到 172 寬（與 idle 相同），離地 17 像素。review 列仍有一格姿勢跳變和殘影，腳本救不回來，要重生（步驟 2 的最後）。

## 步驟 2：本機生成 16 個方向

在 ComfyUI 裝好 **Qwen-Image-2.1 INT8**（`qwen_image_2.1_int8_convrot`、`qwen3vl_8b_int8_convrot`、`qwen_image_2.1_vae_bf16`），並啟動 ComfyUI（預設 127.0.0.1:8188）。

```powershell
python scripts\02_generate_look_directions.py $env:PET_WORK\gen-c1.json c1 20261106 000,090,180,270
```

參數依序是：結果 JSON、標籤、seed、方向清單。可用方向：`000 022.5 045 067.5 090 112.5 135 157.5 180 202.5 225 247.5 270 292.5 315 337.5`，另有 `nod`、`tiltR`、`proud`、`blink` 四個給 review 列用。
圖會存在 `$PET_WORK\generated\zq_<標籤>_<方向>_00001_.png`。

**這個做法為什麼有效（都是實測得到的）：**
1. **只給模型一張參考圖**（idle 第一格，貼在純洋紅 #FF00FF 的 1024×1024 底圖上）。給兩張，其中一張是四方向圖時，模型會照著畫出四宮格。
2. 提示詞寫「只改頭，其他像素不變」，並強調「只畫一隻」。
3. 身體每次都在同一個位置和大小，所以每格自動對齊，不用手動調。

**每個方向要自己挑。** 同一個方向換幾個 seed 生成，用肉眼挑出方向對、身體大小一致的一張，再把挑中的標籤填進 `03_assemble_atlas.py` 的 `ORDER`。玄龍的 180（往下看）最難，換了 3 組 seed、改過一次提示詞才得到身體沒縮小的結果。

review 列：用 `nod,tiltR,proud,blink` 四個方向生成 4 格，標籤用 `rv`（腳本預設這樣讀）。

## 步驟 3：組圖集

```powershell
python scripts\03_assemble_atlas.py
```

做的事：把洋紅底去掉並消除邊緣洋紅色（去色鍵），把每格縮到 93% 以免頭角碰到格子邊緣，對齊 idle 的腳底中心與基準線，組成 1536×2288，輸出 `local-run\atlas_candidate.png`、16 方向循環 `look16.gif` 與 `look16-cells.png`。

## 步驟 4：驗證

驗證腳本來自 OpenAI 的 Pets 外掛（已安裝 Codex 與 Pets 外掛的人，會在 `~\.codex\plugins\cache\openai-curated-remote\work-pets\<版本>\skills\create-pet\scripts\`）。這些腳本是純 Python，在你自己的電腦上跑，**不消耗額度**。本 repo 不轉載它們。

```powershell
$s = "$HOME\.codex\plugins\cache\openai-curated-remote\work-pets\0.1.6\skills\create-pet\scripts"
python $s\validate_atlas.py $env:PET_WORK\local-run\atlas_candidate.png --require-v2 --chroma-key "#FF00FF"
python $s\measure_direction_continuity.py $env:PET_WORK\local-run\atlas_candidate.png --json-out $env:PET_WORK\local-run\continuity.json
```

注意：`--chroma-key` 一定要給 `"#FF00FF"`；預設是綠色 `#00FF00`，用洋紅底卻不給參數，會漏掉洋紅殘邊。
連續性報告的 `warnings` 要逐條看：`interior hole` 是兩腿之間的空隙，不是問題；`center shift` 是方向轉換時頭的位置跳動，要用眼睛看動畫判斷。

## 步驟 5：看動作

打開 `look16.gif` 和各列動畫。重點看 157.5→180、337.5→000，以及 jumping 回到 idle 時有沒有縮放突變。有問題的格回到步驟 2 換 seed，不要手工修圖。

## 步驟 6：打包並安裝

```powershell
python scripts\04_make_pet_package.py
Copy-Item -Recurse $env:PET_WORK\local-run\pet-package "$HOME\.codex\pets\zero"
```

`pet.json` 一定要有 `"spriteVersionNumber": 2`，否則 2288 高的圖會被拒絕。WebP 要用 `exact=True` 儲存（腳本已處理），否則完全透明像素的顏色資料會被改動，驗證會失敗。
裝好後在 Codex 的寵物設定裡看得到，寵物就會顯示在桌面。

## 這條路線的限制（請誠實看待）

- 寵物只存在你這台電腦的 Codex，**沒有上傳到 ChatGPT Pets 雲端**。
- OpenAI 的 Pets 建立規範要求所有寵物影像用 `$imagegen` 生成。本機模型做出來的圖，過了結構驗證，但能不能通過官方上傳審核**沒有驗證過**。
- 方向沒有做三人盲測，只有作者目視。
- 需要約 16 GB 顯示記憶體的 NVIDIA 顯卡（實測 RTX 4060 Ti 16 GB，每張約 30 到 40 秒）。
